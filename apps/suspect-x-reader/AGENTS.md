# 嫌疑人 X 阅读器约定

- 本应用是逐段阅读、线索收集与章节解锁体验；同仓三应用分别维护，当前部署与完整验证以 [仓库 README](../../README.md) 为准。
- 源码入口 `src/main.tsx`、`src/App.tsx`；阅读内容与图像映射在 `src/data/`，进度与音效分别在 `src/hooks/`。
- 使用 pnpm 管理依赖，不用 npm/yarn；本地开发端口 3000，Coze 预览／服务脚本使用 5000，不用 9000。
- 预览脚本应可重复执行，关键环境变量显式设置；先检查端口，避免影响其他服务。
- 修改阅读与线索逻辑时验证章节解锁、进度持久化与键盘操作；音效采用 Web Audio 合成，保留全局开关和用户偏好。
- 修改内容或图片前核对对应章节和素材；作品为非商业交互研究，文学与图像复用、再分发须独立核对权利。
- 在应用目录运行 `pnpm run lint` 与 `pnpm run build`，涉及共享行为时在仓库根运行 `pnpm run verify`，再预览主流程。
- Coze 脚本只适用于该平台，不能用历史平台配置替代仓库当前的独立 Vercel 部署口径。
